# Platform constraints

Properties of Midnight that shape m402's architecture. Each was verified against the running
network or the toolchain rather than taken from documentation alone.

## Proving cost

| Operation | Time |
|---|---|
| Generate a proof (trivial circuit) | **~19s** |
| Verify a proof | **~3.4ms** |

Measured on Midnight Preview with a minimal contract: deploy 20.2s, single state write 18.7s.
This is the floor, not a loaded case — a more complex circuit will not be faster.

**Consequence.** One proof per API call is the accepted cost of this design. Proving happens
on the agent's machine; verification is effectively free. Amortising proof generation is
tracked in the [roadmap](roadmap.md).

## DUST is not a payment asset

DUST is a shielded, **non-transferable** resource used to pay transaction fees. It is
generated by registered NIGHT and consumed as gas. There is no send path.

**Consequence.** DUST cannot be the settlement asset. Settlement is shielded NIGHT.

## Contracts can only pay the caller

`sendShielded` does not create coin ciphertexts, so a contract can reliably deliver shielded
value only to the account invoking it.

**Consequence.** The vault cannot push funds to a merchant. Merchants must **pull** via
`withdraw()`. This is why the design is a vault rather than a direct transfer.

## `disclose()` is a visibility annotation

`disclose()` is a compile-time annotation permitting a witness-derived value to cross into
public visibility — a ledger write, or an exported circuit's return value. It performs no
encryption and does not target a recipient key.

**Consequence.** Selective disclosure must be constructed: a commitment on-chain, with the
opening delivered off-chain encrypted to the auditor's key. See
[`design.md`](design.md#selective-disclosure).

## No Midnight ↔ EVM bridge

The only protocol-level bridge is **Cardano → Midnight, one-way** (cNIGHT → mNIGHT). Two-way
bridging is post-mainnet. EVM connectivity exists today only as third-party work.

**Consequence.** The relayer fronts USDC as a trusted operator and is reimbursed from the
vault. It is not a bridge, and the design does not claim to be one.

## Node version

The Midnight SDK's ESM exports fail to resolve on Node 23 and Node 26. **Node 22 or 24 only.**

Failures surface as `ERR_PACKAGE_PATH_NOT_EXPORTED` inside a `tsx` stack trace, which reads
like a dependency problem rather than a runtime-version problem. Check `node -v` first.

## Network

Development targets **Preview**:

| Service | Endpoint |
|---|---|
| Indexer | `https://indexer.preview.midnight.network/api/v4/graphql` |
| Indexer WS | `wss://indexer.preview.midnight.network/api/v4/graphql/ws` |
| Node RPC | `https://rpc.preview.midnight.network` |
| Faucet | `https://faucet.preview.midnight.network` |
| Proof server | `http://127.0.0.1:6300` (local, Docker) |

The proof server must stay bound to loopback: proof requests carry private witness data and
the service has no authentication.

Indexer subscriptions replay history from genesis, which can take longer than 30 seconds on a
busy address. Short listen windows produce false negatives that are indistinguishable from a
genuine "no activity" result.
